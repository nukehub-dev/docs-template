The docs template exposes a small set of shortcodes you can use in MDX files.

## Callout

Use `<Callout>` to highlight notes, tips, warnings, and successes.

```mdx
<Callout type="tip" title="Tip">
  Use `npm run sync-docs` before building to refresh content.
</Callout>
```

<Callout type="tip" title="Tip">
  Use `npm run sync-docs` before building to refresh content.
</Callout>

<Callout type="warning" title="Warning">
  Remember to update `base` in `src/data/site.ts` when you rename the repository.
</Callout>

## Tabs

Use `<Tabs>` and `<TabItem>` to group alternative instructions.

```mdx
<Tabs defaultValue="npm">
  <TabItem value="npm" label="npm">
    npm install
  </TabItem>
  <TabItem value="pnpm" label="pnpm">
    pnpm install
  </TabItem>
</Tabs>
```

## File tree

Use `<FileTree>` to show directory layouts.

```mdx
<FileTree
  items={[
    { name: "docs", children: [
      { name: "README.md" },
      { name: "tutorials", children: [{ name: "getting-started.md" }] },
    ]},
    { name: "src", children: [
      { name: "components", children: [
        { name: "layout", children: [{ name: "Header.tsx" }] },
      ]},
    ]},
  ]}
/>
```

    B --> C[Build]
    C --> D[Deploy to Pages]
`} />

## Steps

Use `<Steps>` and `<Step>` for numbered procedures.

```mdx
<Steps>
  <Step>Install dependencies with `npm install`.</Step>
  <Step>Run `npm run dev` to start the local server.</Step>
  <Step>Deploy with `git push origin main`.</Step>
</Steps>
```

## Plotly charts

Use `<Plotly>` for interactive charts. Plotly is loaded on demand and renders client-side.

```mdx
<Plotly
  data={[
    {
      x: [1, 2, 3, 4, 5],
      y: [1, 4, 9, 16, 25],
      type: "scatter",
      mode: "lines+markers",
      marker: { color: "#3b82f6" },
    },
  ]}
  layout={{ title: "Quadratic growth" }}
/>
```

## 3D models

Use `<Model3D>` to embed interactive `.glb` models. Three.js is loaded on demand and renders client-side.

```mdx
<Model3D
  src="/docs-template/models/example.glb"
  caption="A sample interactive model."
  autoRotate
/>
```

Place the `.glb` file in `public/` (or any served asset path) and reference it by URL.

## Data tables

Use `<DataTable>` for sortable, searchable, paginated reference tables.

```mdx
<DataTable
  columns={[
    { key: "name", header: "Name", sortable: true },
    { key: "mass", header: "Mass (u)", align: "right", sortable: true },
  ]}
  data={[
    { name: "U-235", mass: "235.0439" },
    { name: "U-238", mass: "238.0508" },
  ]}
  sortable
  searchable
/>
```

## Code blocks

Standard Markdown code fences are syntax highlighted with Shiki.

### Python

```python
from nucleide import from_formula

comp = from_formula("UO2")
print(comp)

for nuclide, fraction in comp.items():
    print(f"{nuclide}: {fraction:.4f}")
```

### C++

```cpp
#include <iostream>
#include <map>
#include <string>

int main() {
    std::map<std::string, double> composition = {
        {"U235", 0.0071},
        {"U238", 0.9929},
        {"O16", 2.0},
    };

    for (const auto& [nuclide, fraction] : composition) {
        std::cout << nuclide << ": " << fraction << "\n";
    }

    return 0;
}
```
